# Wallume — Interactive Live Wallpapers

**216 living scenes that react to your touch.** Pick one, play with it, tune it, then export a
pixel-perfect wallpaper for your phone, tablet or desktop — or record a looping live video.
No accounts, no watermarks, everything rendered locally in your browser.

🔗 **Live app:** https://github.com/Roy-Wanyoike/wallume — runs anywhere Next.js runs.

## ✨ What makes it special

### Touch-reactive scenes
Every wallpaper answers your finger or cursor — tap the sky and **call down lightning**,
touch the water and **watch the fish scatter**, pop bubbles mid-air, launch fireworks,
bend a nebula's gravity, whip sand across the dunes, or summon a shimmer through a
crystal cave. Interactions include:

`flee` · `attract` · `repel` · `ripple` · `spawn` · `strike` · `gust` · `shimmer` · `swirl` · `parallax`

### 24 engine families → 216 named wallpapers
Aquarium, Jelly Realm, Fireworks, Ink Bloom, Nebula Storm, Plasma Orbs, Code Rain,
Meadow Whimsy, Dusk Dunes, Crystal Cave, Storm Cells, Bubble Rise — plus auroras,
oceans, alpine dusk, synthwave grids, fireflies, rain-on-glass, planetary orbits and more.
Every variant has its **own name, tagline, palette rotation, seed and motion defaults**.

### Real-time studio
- Phone **and** desktop/laptop preview mockups with live clock
- Palette swapping + per-channel color fine-tuning
- Speed / density / glow sliders, randomize & re-seed
- Fullscreen immersive mode

### Download anywhere
- PNG export at **device-exact resolutions** — Auto, FHD+, QHD+, iPhone, iPad, and
  desktop Full HD / Quad HD / **4K UHD** / ultrawide / MacBook
- 5-second **live loop video** recording (WebM/MP4) in portrait or landscape
- Copy-image-to-clipboard, shareable design links (`?p=code`)

### Community wall
Upload your own images (resized on-device) — they go live for everyone instantly,
labeled **Coming soon** until interactive downloads ship.

### Installable PWA
Add to Home Screen, offline-capable shell via service worker, app shortcuts.

## 🧱 Tech stack

| Layer | Choice |
|---|---|
| Framework | Next.js 16 (App Router) + TypeScript 5 |
| UI | Tailwind CSS 4 + shadcn/ui + Lucide icons, framer-motion |
| Rendering | Hand-written deterministic Canvas 2D engines (single shared rAF ticker, per-canvas fps budgets, IntersectionObserver pausing) |
| Database | SQLite via Prisma (likes, downloads, share presets, community submissions) |
| PWA | Web manifest + service worker (offline shell) |

### Engine architecture highlights
- **Pure time-driven draw functions** — the same code renders the live preview and the
  static high-res export (`heroTime` produces a beautiful frozen frame).
- **Additive interaction state** — touch impulses live in per-canvas WeakMaps and decay
  to zero, so scenes stay deterministic when no pointer is present.
- **Area-aware particle counts** — scenes scale their populations from phone thumbnails
  to 4K desktop canvases.
- **One shared requestAnimationFrame loop** with per-task fps budgets; canvases outside
  the viewport are paused automatically.

## 🚀 Run it yourself

```bash
bun install
bun run db:push     # create SQLite schema
bun run dev         # http://localhost:3000
```

Production:

```bash
bun run build
bun run start
```

## 📁 Project layout

```
src/lib/wallpapers/
  types.ts      DrawFn / DrawEnv / WallpaperDef contracts
  helpers.ts    palettes, PRNG, per-canvas state, ripple & burst decorators
  engines.ts    12 foundational scenes
  engines2.ts   12 touch-reactive engine families
  catalog.ts    name banks + variant generator → 216 wallpapers
  render.ts     config resolution, PNG/video export, resolution presets
  ticker.ts     shared rAF loop with fps budgets
src/components/wallpaper/
  wallume-app.tsx   state orchestration
  studio.tsx        phone + desktop mockups
  gallery-grid.tsx  search / filter / sort / chunked gallery
  community.tsx     uploads with Coming Soon label
  download-dialog.tsx  PNG + live-loop export
src/app/api/       stats, likes, downloads, presets, community
```
